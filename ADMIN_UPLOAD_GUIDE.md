# 🚀 Admin Bulk Upload - Quick Start

## Доступ к Admin Panel

Откройте в браузере:
```
http://localhost:3000/admin/upload
```

## Как использовать Bulk Upload:

### Шаг 1: Подготовьте файлы
- Видео или аудио файлы
- (Опционально) SRT файлы субтитров

### Шаг 2: Заполните форму
Для каждого медиа файла укажите:
- **Title** - название (обязательно)
- **Type** - video или audio
- **Description** - описание
- **Difficulty** - beginner/intermediate/advanced  
- **Category** - music, movies, podcasts и т.д.
- **Tags** - теги через запятую
- **Media File** - выберите файл (обязательно)
- **Subtitle File** - .srt файл (опционально)

### Шаг 3: Добавьте больше форм
Нажмите "➕ Add Another Media" чтобы добавить еще одно видео

### Шаг 4: Загрузите всё сразу
Нажмите "🚀 Upload All" - все файлы загрузятся автоматически!

## ✨ Преимущества:

- ✅ **Массовая загрузка** - загружайте 5-10 видео за раз
- ✅ **Автоматическая обработка** - Cloudinary + Database
- ✅ **Прогресс в реальном времени** - видите что происходит
- ✅ **Парсинг SRT** - автоматически добавляет субтитры
- ✅ **Удобный интерфейс** - заполнили формы и всё!

## 📝 Примечания:

1. **SRT файлы**: Если загружаете .srt файл, он автоматически распарсится
   - Создаст временные метки для каждой строки
   - Добавит в базу данных
   - НО: переводы и word-timing нужно добавлять вручную в БД

2. **Размер файлов**: Cloudinary бесплатный план - до 25 GB
   - Можете загружать видео до 100MB каждое

3. **Безопасность**: Позже добавим authentication для admin panel
